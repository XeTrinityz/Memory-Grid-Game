# Memory Grid — Find & Remember

A simple memory game

## Structure

- `index.html` — Main HTML document linking the external CSS and JS.
- `css/style.css` — All styles extracted from the original inline `<style>` block.
- `js/app.js` — All game logic extracted from the original inline `<script>` block.

## How to run

- Open `index.html` in your browser. No build steps are required.

## Notes

- Google Fonts are loaded via `@import` at the top of `css/style.css` as in the original file.
- No external assets are required; all visuals are CSS and emoji-based.
