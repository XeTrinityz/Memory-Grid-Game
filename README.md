# Memory Grid — Find & Remember

A simple memory game

## Structure

- `index.html` — Main HTML document linking the external CSS and JS.
- `css/style.css` — All styles.
- `js/app.js` — All game logic.

## How to run

- Open `index.html` in your browser. No build steps are required.

## Notes

- Google Fonts are loaded via `@import` at the top of `css/style.css`.
- No external assets are required; all visuals are CSS and emoji-based.
